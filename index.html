Jacobi

Método 01 · Iterativo

Jacobi

Calcula todas las incógnitas de una iteración usando únicamente los valores de la iteración anterior. Como ningún cálculo depende de otro dentro de la misma iteración, los tres (o los N) se pueden resolver en paralelo, que es la idea central detrás de por qué existe, y de su principal ventaja frente a Gauss-Seidel.

Jacobi / Teoría

Teoría

Método de Jacobi

Es un método iterativo para resolver sistemas de ecuaciones lineales Ax = b. En vez de resolver el sistema de una sola vez (como Gauss o Cramer), parte de un vector inicial x⁽⁰⁾ y lo va refinando iteración a iteración hasta acercarse a la solución real.

1. El requisito fundamental: La Matriz Diagonalmente Dominante

Lo primero que se debe hacer para aplicar el método de Jacobi (o cualquier método iterativo) en la resolución de un sistema de ecuaciones es verificar su convergencia a una solución.

  • Para lograr esto, la regla de oro es comprobar que la matriz de los coeficientes sea diagonalmente dominante.
  • La condición matemática establece que el valor absoluto de cada elemento de la diagonal principal (aii) tiene que ser mayor o igual a la suma en valor absoluto del resto de las componentes de cada fila (aij).
  • En fórmula, esto se expresa de la siguiente manera: |aii| ≥ Σj=1n |aij|.
  • ¿Por qué es vital este paso? Al ser un método iterativo, si no se verificara esta condición, podríamos estar haciendo iteraciones indefinidamente y nunca llegaríamos a resolver el problema.
  • Si la matriz cumple con ser diagonalmente dominante, esto nos da la total certeza de que el problema se va a poder resolver, incluso si hubiera que aplicar miles de iteraciones.
  • Es importante saber que esta condición es suficiente, pero no necesaria. Esto significa que es suficiente que sea diagonalmente dominante para tener certeza de que hay solución, pero el sistema podría no ser diagonalmente dominante e igualmente tener solución (aunque al no tener la certeza, no aplicamos el método a ciegas).
  • Reordenamiento: Si la matriz original no es diagonalmente dominante, a veces se pueden intercalar filas (o columnas) para llevar el sistema a una matriz que sí lo sea. Recién sobre esta nueva matriz reordenada es seguro aplicar el método.

2. Fundamento del Algoritmo iterativo

Una vez garantizada la convergencia por la diagonal, el método consiste en ir aproximándose al resultado paso a paso.

  • El método de Jacobi calcula los valores de las incógnitas (por ejemplo x, y, z) en la iteración actual (llamada iteración "k").
  • Para hacer este cálculo, se basa exclusivamente en los valores de las incógnitas que se calcularon en la iteración anterior (llamada iteración "k-1").
  • Debido a que siempre requiere los datos del paso previo, el método necesita obligatoriamente partir de un vector inicial, que llamamos x(0).
  • Este vector inicial permite obtener el resultado de la primera iteración, y luego con ese nuevo resultado se calcula la segunda, y así sucesivamente.

3. Expresión Matemática General

La fórmula general de la matriz iterativa del método de Jacobi, que indica cómo se debe despejar cada incógnita de la diagonal, es la siguiente:

xi(k)  =  1aii [ bi − nΣj=1 aij xj(k−1) ]

Flujo de datos: todo en paralelo

Ventajas y limitaciones

VENTAJAS

  • Los cálculos de una iteración son independientes entre sí → se puede paralelizar.
  • Implementación simple y directa.

LIMITACIONES

  • Converge más lento que Gauss-Seidel.
  • Requiere guardar dos vectores completos en memoria (actual y anterior).

Jacobi / Práctica

Práctica

Resolución paso a paso

Problema: Dado el siguiente sistema de ecuaciones lineales, realizar 3 iteraciones por el método de Jacobi partiendo del vector inicial x(0) = {0, 0, 0}.

3x + y + z = 4 2x + 5y + z = -1 -x + y + 3z = 4

Paso 1: Armar la Matriz Iterativa

Para aplicar el método de Jacobi, primero debemos despejar de cada ecuación la incógnita correspondiente a la diagonal principal (x de la primera, y de la segunda, z de la tercera). Luego, agregamos los índices "k" para la iteración actual y "k-1" para los valores de la iteración anterior:

x(k) =13[ 4 − ( y(k−1) + z(k−1) ) ]
y(k) =15[ −1 − ( 2x(k−1) + z(k−1) ) ]
z(k) =13[ 4 − ( −x(k−1) + y(k−1) ) ]

Paso 2: Ejecutar las 3 Iteraciones

Iteración 1 (k = 1)

Reemplazamos en las fórmulas los valores del vector inicial, donde x = 0, y = 0 y z = 0.

  • x(1) = ⅓ [4 − (0 + 0)] = 4/3
  • y(1) = ⅕ [−1 − (2(0) + 0)] = −1/5
  • z(1) = ⅓ [4 − (−0 + 0)] = 4/3

Vector resultante 1: x(1) = {4/3, −1/5, 4/3}

Iteración 2 (k = 2)

Ahora utilizamos los valores obtenidos en la iteración 1: x = 4/3, y = −1/5 y z = 4/3.

  • x(2) = ⅓ [4 − (−1/5 + 4/3)] = 0.95
  • y(2) = ⅕ [−1 − (2(4/3) + 4/3)] = −1
  • z(2) = ⅓ [4 − (−4/3 + (−1/5))] = 1.84

Vector resultante 2: x(2) = {0.95, −1, 1.84}

Iteración 3 (k = 3)

Finalmente, utilizamos los valores obtenidos en la iteración 2: x = 0.95, y = −1 y z = 1.84.

  • x(3) = ⅓ [4 − (−1 + 1.84)] = 1.053
  • y(3) = ⅕ [−1 − (2(0.95) + 1.84)] = −0.948
  • z(3) = ⅓ [4 − (−0.95 + (−1))] = 1.983

Vector resultante 3: x(3) = {1.053, −0.948, 1.983}

Conclusión del Ejercicio

La solución exacta de este sistema de ecuaciones es x = {1, −1, 2}. Como podemos observar, en tan solo tres iteraciones hemos obtenido un resultado bastante cercano a la solución exacta.

Gauss-Seidel

Método 02 · Iterativo

Gauss-Seidel

Parte de la misma idea que Jacobi, pero con un cambio clave: apenas calcula un valor nuevo dentro de una iteración, lo usa inmediatamente para calcular el siguiente. Esa combinación de valores nuevos y viejos dentro de la misma iteración acelera la convergencia, a costa de perder la posibilidad de paralelizar.

Gauss-Seidel / Teoría

Teoría

Método de Gauss-Seidel

Es una variante del método de Jacobi. Se despejan las mismas ecuaciones y se verifica la misma condición de convergencia, pero cambia cómo se combinan los valores durante el cálculo de cada iteración.

1. El requisito compartido: La Convergencia

Al igual que ocurre en el método de Jacobi, el paso indispensable antes de comenzar a resolver el sistema por Gauss-Seidel es verificar su convergencia a una solución.

  • Ambos métodos comparten la misma regla: se debe verificar que la matriz de los coeficientes sea diagonalmente dominante.
  • Si la matriz no cumple esta condición originalmente, se debe intentar reordenar las filas antes de aplicar el algoritmo. Al igual que en Jacobi, si la matriz es diagonalmente dominante, tenemos la certeza de que el problema se resolverá, siendo esta una condición suficiente pero no necesaria.

2. Fundamento del Algoritmo: La mejora frente a Jacobi

La preparación del sistema es idéntica a la de Jacobi: se debe despejar una incógnita de cada ecuación (la correspondiente a la diagonal principal). Sin embargo, la gran diferencia radica en cómo se calculan los valores durante las iteraciones.

  • El método de Gauss-Seidel calcula los valores de las incógnitas en la iteración actual (iteración "k") basándose en una combinación de datos: utiliza los valores de la iteración anterior ("k-1") junto con los valores que ya se han calculado en esa misma iteración "k".
  • Por ejemplo, para calcular la segunda variable ("y") en la iteración 1, el método ya no usa la "x" del vector inicial (iteración 0), sino que utiliza la "x" que se acaba de calcular pasos atrás en la misma iteración 1, porque es un valor "mejor" o más actualizado. Para las variables que aún no se calcularon en esa iteración (como la "z"), sí sigue tomando el valor de la iteración anterior.
  • La gran ventaja: Esta actualización inmediata de los datos durante el cálculo hace que el método se acelere y logre una convergencia mucho más rápida que el método de Jacobi.
  • Al igual que Jacobi, este método también requiere de un vector inicial (denominado x(0)) para poder empezar a trabajar en la primera iteración.

3. Expresión Matemática General

La fórmula general para el método de Gauss-Seidel refleja esta combinación de datos de la iteración actual y la anterior:

xi(k)  =  1aii [ bi − i−1Σj=1 aijxj(k) − nΣj=i+1 aijxj(k−1) ]

Para calcular xi en la iteración k, se usan los valores ya actualizados (j<i, de esta misma iteración k) y los valores todavía viejos (j>i, de la iteración k-1).

Flujo de datos: mezcla secuencial

Ventajas y limitaciones

VENTAJAS

  • Converge más rápido que Jacobi (usa valores ya actualizados).
  • Necesita menos memoria: se puede ir pisando el mismo vector.

LIMITACIONES

  • Es secuencial por naturaleza → no se paraleliza fácilmente.
  • El orden de las ecuaciones puede afectar la velocidad de convergencia.

Gauss-Seidel / Práctica

Práctica

Resolución paso a paso

Problema: Dado el mismo sistema de ecuaciones lineales, realizar 3 iteraciones por el método de Gauss-Seidel partiendo del vector inicial x(0) = {4/3, −1/5, 4/3}.

3x + y + z = 4 2x + 5y + z = -1 -x + y + 3z = 4

Paso 1: Armar la Matriz Iterativa

El despeje inicial de las ecuaciones es idéntico al de Jacobi. La diferencia crucial está en los índices: para calcular y(k) usamos la x(k) que acabamos de averiguar, y para z(k) usamos tanto la x(k) como la y(k) recién calculadas:

x(k) =13[ 4 − ( y(k−1) + z(k−1) ) ]
y(k) =15[ −1 − ( 2x(k) + z(k−1) ) ]
z(k) =13[ 4 − ( −x(k) + y(k) ) ]

Paso 2: Ejecutar las 3 Iteraciones

Iteración 1 (k = 1)

Para calcular x, usamos y y z del vector inicial. Pero atención: para calcular y, ya usamos el nuevo valor de x (0.955); y para z, usamos los nuevos valores de x (0.955) e y (−0.8488).

  • x(1) = ⅓ [4 − (−1/5 + 4/3)] = 0.955
  • y(1) = ⅕ [−1 − (2(0.955) + 4/3)] = −0.8488
  • z(1) = ⅓ [4 − (−0.955 + (−0.8488))] = 1.9347

Vector resultante 1: x(1) = {0.955, −0.8488, 1.9347}

Iteración 2 (k = 2)

Repetimos la lógica secuencial, arrastrando siempre el dato más actualizado que tengamos.

  • x(2) = ⅓ [4 − (−0.8488 + 1.9347)] = 0.9713
  • y(2) = ⅕ [−1 − (2(0.9713) + 1.9347)] = −0.9754
  • z(2) = ⅓ [4 − (−0.9713 + (−0.9754))] = 1.9822

Vector resultante 2: x(2) = {0.9713, −0.9754, 1.9822}

Iteración 3 (k = 3)

Última iteración pedida en el ejercicio.

  • x(3) = ⅓ [4 − (−0.9754 + 1.9822)] = 0.9977
  • y(3) = ⅕ [−1 − (2(0.9977) + 1.9822)] = −0.9955
  • z(3) = ⅓ [4 − (−0.9977 + (−0.9955))] = 1.9977

Vector resultante 3: x(3) = {0.9977, −0.9955, 1.9977}

Conclusión del Ejercicio

La solución exacta del problema es x = {1, −1, 2}. Como se puede observar, en solo tres iteraciones con Gauss-Seidel llegamos a un resultado sumamente preciso, demostrando en la práctica cómo la actualización secuencial de variables acelera la convergencia en comparación con el método de Jacobi.
