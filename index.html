Jacobi

Método 01 · Iterativo

Jacobi

Calcula todas las incógnitas de una iteración usando únicamente los valores de la iteración anterior. Como ningún cálculo depende de otro dentro de la misma iteración, los tres (o los N) se pueden resolver en paralelo — es la idea central detrás de por qué existe, y de su principal ventaja frente a Gauss-Seidel.

Jacobi / Teoría

Teoría

Método de Jacobi

Es un método iterativo para resolver sistemas de ecuaciones lineales Ax = b. En vez de resolver el sistema de una sola vez (como Gauss o Cramer), parte de un vector inicial x⁽⁰⁾ y lo va refinando iteración a iteración hasta acercarse a la solución real.

Condición de convergencia

Antes de iterar hay que verificar que la matriz de coeficientes sea diagonalmente dominante:

|a_ii| ≥ Σ_(j≠i) |a_ij| para cada fila i

El valor absoluto de cada elemento de la diagonal principal tiene que ser mayor o igual a la suma en valor absoluto del resto de los elementos de esa fila.

Suficiente, no necesaria. Si se cumple, hay garantía matemática de convergencia. Si no se cumple, el sistema podría tener solución igual, pero al no haber garantía, no se aplica el método con confianza. A veces reordenando filas (o columnas) se puede llevar la matriz a una forma diagonalmente dominante.

Fórmula general

x_i^(k) = (1 / a_ii) · [ b_i − Σ_(j≠i) a_ij · x_j^(k-1) ] ∀i=1:n ∀k=1:n

Se despeja cada incógnita de su propia ecuación, y se calcula la iteración k reemplazando todos los valores por los de la iteración k-1.

Flujo de datos: todo en paralelo

Ventajas y limitaciones

VENTAJAS

  • Los cálculos de una iteración son independientes entre sí → se puede paralelizar.
  • Implementación simple y directa.

LIMITACIONES

  • Converge más lento que Gauss-Seidel.
  • Requiere guardar dos vectores completos en memoria (actual y anterior).

Jacobi / Práctica

Práctica

Ejercicio resuelto

Sistema a resolver, con vector inicial x⁽⁰⁾ = (0, 0, 0):

3x + y + z = 4 2x + 5y + z = -1 -x + y + 3z = 4

1. Verificación de convergencia

Matriz de coeficientes:

3 1 1 2 5 1 -1 1 3

|3| ≥ |1|+|1| → 3≥2 ✓  |5| ≥ |2|+|1| → 5≥3 ✓  |3| ≥ |-1|+|1| → 3≥2 ✓ → es diagonalmente dominante, se puede aplicar el método con garantía de convergencia.

2. Se despeja cada incógnita

x^(k) = (1/3)·[ 4 − ( y^(k-1) + z^(k-1) ) ] y^(k) = (1/5)·[ -1 − ( 2x^(k-1) + z^(k-1) ) ] z^(k) = (1/3)·[ 4 − ( -x^(k-1) + y^(k-1) ) ]

3. Iteraciones

Iteración k = 1 (reemplazando x⁽⁰⁾=y⁽⁰⁾=z⁽⁰⁾=0)

x⁽¹⁾ = ⅓[4−(0+0)] = 4/3  ·  y⁽¹⁾ = ⅕[-1−(0+0)] = -1/5  ·  z⁽¹⁾ = ⅓[4−(0+0)] = 4/3

Iteración k = 2

x⁽²⁾ = ⅓[4−(-0.2+1.333)] = 0.95  ·  y⁽²⁾ = ⅕[-1−(2·1.333+1.333)] = -1  ·  z⁽²⁾ = ⅓[4−(-1.333-0.2)] = 1.84

Iteración k = 3

x⁽³⁾ = ⅓[4−(-1+1.84)] = 1.053  ·  y⁽³⁾ = ⅕[-1−(2·0.95+1.84)] = -0.948  ·  z⁽³⁾ = ⅓[4−(-0.95-1)] = 1.983

Gauss-Seidel

Método 02 · Iterativo

Gauss-Seidel

Parte de la misma idea que Jacobi, pero con un cambio clave: apenas calcula un valor nuevo dentro de una iteración, lo usa inmediatamente para calcular el siguiente. Esa combinación de valores nuevos y viejos dentro de la misma iteración acelera la convergencia, a costa de perder la posibilidad de paralelizar.

Gauss-Seidel / Teoría

Teoría

Método de Gauss-Seidel

Es una variante del método de Jacobi. Se despejan las mismas ecuaciones y se verifica la misma condición de convergencia, pero cambia cómo se combinan los valores durante el cálculo de cada iteración.

Condición de convergencia

Igual que en Jacobi: la matriz de coeficientes tiene que ser diagonalmente dominante.

|a_ii| ≥ Σ_(j≠i) |a_ij| para cada fila i
Suficiente, no necesaria. Si se cumple, hay garantía de convergencia; si no se cumple, el método no se aplica con confianza, aunque el sistema pudiera tener solución igual.

Fórmula general

x_i^(k) = (1 / a_ii) · [ b_i − Σ_(j<i) a_ij·x_j^(k) − Σ_(j>i) a_ij·x_j^(k-1) ] ∀i=1:n ∀k=1:n

Para calcular x_i en la iteración k, se usan los valores ya actualizados (j<i, de esta misma iteración k) y los valores todavía viejos (j>i, de la iteración k-1).

Flujo de datos: mezcla secuencial

Ventajas y limitaciones

VENTAJAS

  • Converge más rápido que Jacobi (usa valores ya actualizados).
  • Necesita menos memoria: se puede ir pisando el mismo vector.

LIMITACIONES

  • Es secuencial por naturaleza → no se paraleliza fácilmente.
  • El orden de las ecuaciones puede afectar la velocidad de convergencia.

Gauss-Seidel / Práctica

Práctica

Ejercicio resuelto

Mismo sistema, con vector inicial x⁽⁰⁾ = (4/3, -1/5, 4/3):

3x + y + z = 4 2x + 5y + z = -1 -x + y + 3z = 4

La verificación de convergencia es la misma que en Jacobi (la matriz es diagonalmente dominante), y las ecuaciones despejadas también son las mismas. Lo que cambia es cómo se combinan los valores al iterar:

x^(k) = (1/3)·[ 4 − ( y^(k-1) + z^(k-1) ) ] y^(k) = (1/5)·[ -1 − ( 2x^(k) + z^(k-1) ) ] z^(k) = (1/3)·[ 4 − ( -x^(k) + y^(k) ) ]

Iteraciones

Iteración k = 1

x⁽¹⁾ = ⅓[4−(-0.2+1.333)] = 0.955  ·  y⁽¹⁾ = ⅕[-1−(2·0.955+1.333)] = -0.8488  (ya usa x⁽¹⁾)  ·  z⁽¹⁾ = ⅓[4−(-0.955-0.8488)] = 1.9347  (ya usa x⁽¹⁾ e y⁽¹⁾)

Iteración k = 2

x⁽²⁾ = 0.9713  ·  y⁽²⁾ = -0.9754  ·  z⁽²⁾ = 1.9822

Iteración k = 3

x⁽³⁾ = 0.9977  ·  y⁽³⁾ = -0.9955  ·  z⁽³⁾ = 1.9977
